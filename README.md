# Vehicle Rental System

A vehicle rental system built with Python and Object-Oriented Programming (OOP).

## Features

- Car, motorcycle, and truck management
- Vehicle inheritance
- Method overriding
- Polymorphism
- Rental price calculation
- Input validation
- Error handling with try-except
- Interactive menu system

## Technologies

- Python
- Object-Oriented Programming (OOP)
- Inheritance
- Polymorphism
- try-except
- while loop

## Project Purpose

This project was created to practice Python OOP concepts and build a simple vehicle rental system.
